## Instructions for Creating GIFs

You can create these animated GIFs by:

1. **Screen Recording**: Record your screen while demonstrating the concept
2. **Convert to GIF**: Use tools like:
   - **FFmpeg**: `ffmpeg -i recording.mp4 -vf "fps=10,scale=800:-1:flags=lanczos" output.gif`
   - **Online tools**: ezgif.com, gifski, etc.
3. **Optimize**: Keep file size under 2MB for fast loading
4. **Upload**: Use the Master Editor upload endpoint or place in `/app/backend/uploads/image/`
